## Project Overview

SwiftVisa is an AI-based visa eligibility screening agent that helps applicants understand their visa eligibility requirements.

## Requirements

- langchain
- langchain-community
- pypdf2
- sentence-transformers
- faiss-cpu
- streamlit
- python-dotenv

## Setup

1. Clone this repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Directory Structure

- `KB/` - Knowledge Base files
- `assets/` - Asset files
- `config/` - Configuration files
- `logs/` - Log files
- `models/` - Model files
- `scripts/` - Utility scripts
- `utils/` - Utility modules
- `vectorstore/` - Vector store data
